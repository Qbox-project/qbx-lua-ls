# Contributing has moved to qbx-lua

`qbx-lua-ls` has merged into the [Qbox Lua tooling workspace](https://github.com/Qbox-project/qbx-lua).
This repository is archived; open new language-server issues and pull requests in `qbx-lua`.

Clone that repository to work on the server and its shared parser, formatter, analysis and
FiveM data crates in one checkout. Shared API and server changes belong in the same pull request.

- [Workspace contribution guide](https://github.com/Qbox-project/qbx-lua/blob/main/CONTRIBUTING.md)
- [Language-server development guide](https://github.com/Qbox-project/qbx-lua/blob/main/crates/qbx_lua_ls/CONTRIBUTING.md)
- [Current server source](https://github.com/Qbox-project/qbx-lua/tree/main/crates/qbx_lua_ls)
- [Migration and preserved history](https://github.com/Qbox-project/qbx-lua/blob/main/docs/repository-migration.md)

Editor adapters and interfaces remain in
[qbx-editor](https://github.com/Qbox-project/qbx-editor).
